# Cairo

Bundled offline under the SIL Open Font License 1.1 in `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/cairo

The official `Cairo[slnt,wght].ttf` (version 3.130) was downloaded from the
Google Fonts repository. The six static upright files were instantiated with
fontTools 4.68.0 at `slnt=0`, and `wght=400,500,600,700,800,900`. Each resulting
font's OS/2 weight class matches its Flutter declaration; every font contains
Arabic and Latin glyphs. These are actual weight instances, not copied regular
fonts or synthetic bold. No font download is performed by the application.
